# CoRe – AI-Based Course Recommendation System

link: https://co-re-nextjs-fastapi.vercel.app/

CoRe is a full stack web application developed as a project for the **Introduction to Artificial Intelligence** course.  
The system provides **personalized course or field recommendations** based on academic performance, interests, and career goals using a machine learning model (Decision Tree).

---

## 🎓 Academic Context
- **Course:** Introduction to Artificial Intelligence  
- **Project Type:** Final Project  

---

## 🧠 Project Overview
Users input:
- Math, Science, and English scores
- Main interest
- Career goal  

The backend processes this data using a trained **Decision Tree model** and returns a recommendation.  
All results are securely stored and associated with the authenticated user.

---

## 🛠 Tech Stack

**Frontend**
- Next.js
- Tailwind CSS

**Backend**
- FastAPI
- SQLAlchemy
- JWT Authentication

**Artificial Intelligence**
- Decision Tree (scikit-learn)
- Joblib (model persistence)
